02สาเหตุราก (หลักฐานจากการทดลองในเครื่อง)

2.1 การ์ดจอ — Apple ถอดโค้ด GCN 1.0 ออกจากไดรเวอร์

ไดรเวอร์ที่ควรขับ D500 คือ AMDRadeonX4000.kext ตอนนี้มันมีอยู่บนดิสก์ แต่รายการ PCI ที่รองรับถูกเปลี่ยนไปเป็นรุ่น Polaris (GCN 4) ทั้งหมด:

04สิ่งที่ผู้พัฒนา patch ต้องรู้

หากจะให้สองส่วนนี้ทำงานบน macOS 26 ต้องแก้ในระดับที่ลึกกว่า kext injection ปกติ:

ส่วนสิ่งที่ต้องทำเหตุผล
กราฟิก GCN 1.0 ติดตั้งไดรเวอร์ AMD ยุคที่ยังรองรับ Tahiti (Monterey–Ventura) พร้อม patch framework ที่เกี่ยวข้องลง root volume — เทียบเท่า OCLP “Legacy Metal” patch แต่ต้อง port ให้เข้ากับ Tahoe บน Tahoe kext ตัวใหม่ไม่มีโค้ด Tahiti และเฟรมเวิร์กเปลี่ยน ABI ⇒ ฉีด kext เดี่ยวจะ panic
USB FL1100 ต้องหาสาเหตุที่ไดรเวอร์ที่จับคู่แล้วไม่สร้างพอร์ต (init ออกที่ ~1 ms) แล้ว patch/แทนที่ personality หรือแก้การ merge port map ในระดับที่ไดรเวอร์ยอมใช้ ไดรเวอร์มี + แผนที่พอร์ตมี ⇒ ตัวขวางอยู่ที่การ init ไม่ใช่ kext หาย
KDK ใช้ KDK_26.7_25G229.kdk (ติดตั้งอยู่แล้วในเครื่อง) เป็นฐาน link ไดรเวอร์ OCLP-Mod merge KDK กับ root volume สำเร็จ ⇒ เส้นทางนี้ใช้งานได้จริง
ข้อควรระวังสำหรับผู้ทดลอง การทดลองกับ kext กราฟิก/USB ในระดับ kernel บนเครื่องนี้ ไม่มีการกู้ระยะไกล (ไม่มีคีย์บอร์ด · ไม่มีจอใช้ได้ · ถ้าไม่บูตจะ SSH ไม่ขึ้น) แนวทางกู้เดียวคือ Thunderbolt Target Disk Mode ต่อกับอีกเครื่อง (เช่น Mac mini) — ควรเตรียมไว้ก่อนทุกครั้งที่จะทดลอง

06สิ่งที่ทำได้ตอนนี้

  • ใช้เป็น headless ผ่าน SSH — ใช้งานได้เต็มรูปแบบ (งานไฟล์ · คำสั่ง · server · backup)
  • WiFi + Audio — patch ติดตั้งแล้ว; Wi-Fi ยังสลับเป็น Off อยู่ เปิดได้จาก System Settings หรือ CLI
  • GUI บนเครื่องนี้ — ไม่สามารถใช้ได้จนกว่าจะมีไดรเวอร์ GCN 1.0 สำหรับ Tahoe (WindowServer ล้มเป็นช่วง ๆ; จอผ่าน Screen Sharing จะดำ)
  • ทางเลือกสำหรับงานที่ต้องมีหน้าจอ — ใช้ Mac mini (Tahoe · GPU/USB ทำงาน) หรือ kaiwa.local (macOS 15 · HD 630 ใช้งานได้)
